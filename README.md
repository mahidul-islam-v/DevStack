  ## About

  Dev Stack is an interactive catalog for exploring the tools and technologies used to build modern software. Browse options across frontend, backend, databases, languages, styling, DevOps, and developer tools, then assemble a personal stack as you go.

  ## Features

  - Browse technology cards with descriptions, categories, difficulty levels, ratings, and labels.
  - Add technologies to a live **Your Stack** panel.
  - Remove individual selections or clear the entire stack.
  - Get feedback when items are added or removed.
  - View a loading indicator while the technology catalog loads.
  - Responsive layout for desktop and mobile screens.

  ## Built With

  - [React 19](https://react.dev/) and [TypeScript](https://www.typescriptlang.org/)
  - [Vite](https://vite.dev/) for development and production builds
  - [Tailwind CSS 4](https://tailwindcss.com/) and [DaisyUI](https://daisyui.com/) for styling
  - [React Icons](https://react-icons.github.io/react-icons/) for icons
  - [React Toastify](https://fkhadra.github.io/react-toastify/) for notifications

  ## Get Started

  You’ll need [Node.js](https://nodejs.org/) and npm installed.

  ```bash
  git clone https://github.com/mahidul-islam-v/DevStack
  cd dev-stack
  npm install
  npm run dev
````

Open the local URL printed by Vite to use the app.

## Available Scripts
